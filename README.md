# Science Centre Minecraft project installers
This software is used to conveniently install both [Minecraft Forge](https://www.minecraftforge.net) and the Minecraft mods required to play on the Science Centre Minecraft project servers in the desired settings. Note that this is a modified version of the official [Minecraft Forge](https://www.minecraftforge.net) installer.

# Building
To build and package all installers, [MethodScript](https://methodscript.com) ([download](https://methodscript.com/docs/3.3.5//Download.html)) cmdline mode is required. Installing is as simple as executing `buildAllInstallers.mse` (with `mscript.exe`) or running `java -jar MethodScript.jar cmdline buildAllInstallers.mse`. The installers will be placed in the `build/libs` directory.
